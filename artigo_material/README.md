# Material de apoio para o artigo

Esta pasta concentra o que precisa estar pronto antes de escrever o artigo no template `template_artigo_congresso_unisenai/main.tex`.

## Arquivos

- `checklist-artigo.md`: lista macro do que precisa estar concluido.
- `mapa-secoes.md`: como cada secao do template deve ser preenchida e quais evidencias usar.
- `referencias-candidatas.md`: artigos e fontes tecnicas candidatas, com papel de cada uma no texto.
- `referencias-candidatas.bib`: entradas BibTeX iniciais para migrar depois para `template_artigo_congresso_unisenai/referencias.bib`.
- `plano-experimentos.md`: o que executar para gerar resultados rastreaveis.
- `inventario-dados.md`: quais dados, tabelas e graficos serao necessarios.
- `decisoes-artigo.md`: decisões assumidas para avançar o artigo sem depender de novas buscas ou execuções pesadas.

## Regra de trabalho

Nada desta pasta deve ser tratado como resultado final se ainda nao tiver arquivo de origem, log, CSV, referencia verificada ou execucao registrada em `testes/`.
